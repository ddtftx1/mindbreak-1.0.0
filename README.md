# 精神污染 Mindbreak

> 一个不崩游戏、只崩你的 Minecraft 模组。
> 适用于 **Minecraft 1.21.1 + Fabric**，纯服务端逻辑，不需要客户端也装。

你正在挖矿，方块突然跑了。
你正在睡觉，床拒绝了你。
你打死一只僵尸，它开始阴阳怪气。
你打开背包，发现东西全被重新排列了。
这不是 bug，这是特性。欢迎来到《精神污染》。

---

## 一、这个模组到底干了什么

安装后，只要你在游戏里活着，就会平均每 8～25 秒被搞一次（按强度不同）。所有整活都通过随机事件 + 行为回调实现，**不会真的让游戏崩溃**，但会让你的精神状态发生不可逆的变化。

### 1. 聊天栏诈骗（你永远不知道哪句是真的）

- 每隔一段时间弹出莫名其妙的消息（"你的显卡刚刚对你竖起了中指。"）
- 假成就："获得了成就：精神状态稳定！"
- 假死亡："☠ 某某 死了！"——三秒后："……开个玩笑。"
- **伪造玩家发言**：Notch、Herobrine、Steve，甚至"一只鸡"会突然在聊天栏说话（"我在你后面。"）
- **假玩家进服/退服提示**：明明没人来，却提示"Steve 加入了游戏"
- 全村广播系统故障、村民背后议论你、系统重新计算你的价值（结果：0）
- **你打字说话有 18% 概率被曲解**：加"（不是）"、倒着念、变成"【未经审核】"版本，再用你的名字发出去

### 2. 背包不如没有

- **物品栏洗牌**：36 格随机重排，找东西？祝你好运
- **物品被偷**：随机偷走一件东西，10～20 秒后小偷会还回来，还说"谢谢"
- **物品被诅咒**：随机一件物品改名"被诅咒的 XXX"
- **快捷栏自己换手**、**手里的东西自己掉地上**（它说它不想拿）
- **天上掉礼物**：神秘人塞给你"极品泥土""限量版土豆""传家宝""某人的遗物"
- 挖到"钻石"——仔细一看是土

### 3. 你的身体不属于你

- 饥饿值突然清零、突然全满（"你突然饱了，但你什么都没吃"）
- 随机获得飘浮/加速/缓慢/发光/反胃
- 自己打自己（"你的武器突然对你产生了兴趣。"）
- **脖子自己转**：视角被强行甩到奇怪的角度
- **头顶掉铁砧**：头上 8 格高的地方凭空出现一个铁砧，附赠"小心头顶。"
- **脚下变冰**：你踩的地面突然变成冰，滑不滑看运气
- 被方块吓死、被自己的存在伤害
- 经验值随机上涨（"知识并没有增加"）

### 4. 位移与方向感

- **小传送**：突然被扔到附近 16 格内的某处
- **强制转身**：视角被拧转 90°～270°
- **混乱珍珠**：直接扔到 100 格开外

### 5. 生物行为艺术

- **鸡你太美**：身边突然出现 5 只名叫"鸡你太美"的鸡
- **猪队友**：3 只"猪队友 N 号"出现在你身边，它们不打算帮忙
- **苦力怕道歉**："对不起，走错了。"
- **社恐末影人**：一只不会动、不想说话的末影人出现在附近
- **怪物嘴臭**：附近的怪会点名对你进行语言攻击
- **怪物兴奋**：附近的怪突然全部加速+力量
- **位置互换**：多人游戏时，你和另一个玩家的位置会突然对调
- 打怪时你的武器有 4% 概率背刺你自己

### 6. 世界本身开始发疯

- **方块逃跑**：挖方块时有 5% 概率被取消，方块"逃走了"
- **方块重生**：挖掉的方块变成南瓜/西瓜/蛋糕/唱片机/海绵/史莱姆块长回来
- **放置方块变形**：你放的方块在最后一刻变成别的东西
- **床拒绝你**：想睡觉？床会把你抬到天上并说不
- **TNT 跟踪**：背后 4 格突然出现一个点燃的 TNT，引信 4 秒，建议跑
- **天气乱变**（雷暴随机）、**时间乱跳**（白天黑夜随机）
- **钻石雨**：天上掉钻石，其中一半是土
- **假钻石矿**：你身边的石头突然变成钻石矿，3 秒后变回石头（"你发现了钻石矿！……可惜它们只存在 3 秒。"）
- **不死图腾诈尸**：如果你带着不死图腾，它会"抖一下"并说今天不想上班
- 环境音效随机吓人（恶魂尖叫、凋灵出生、远古守卫者诅咒……）

### 7. 死亡也不太安详

- 死亡时有 60% 概率全村通报你的"遗言"：
  - "死于被自己的影子背叛。"
  - "试图和苦力怕讲道理，失败。"
  - "的尸体上写着一行字：我不信邪。"

## 二、五件神器

都可以用 `/mindbreak gift` 直接领取，也有合成配方（都是些不太对劲的材料）。

| 物品 | 效果 | 合成 |
| --- | --- | --- |
| **离谱棒** | 右键随机触发一个整活事件 | 木棍 + 火药 + 腐肉 |
| **嘴臭之书** | 对全服（或最近的玩家）输出一句阴阳怪气，自己反胃 | 书 + 墨囊 + 腐肉 |
| **混乱珍珠** | 随机传送到约 100 格外的地面上 | 末影珍珠 + 萤石粉 + 火药 |
| **后悔蛋糕** | 吃了之后：反胃 + 中毒。名字就是预警 | 蛋糕 + 腐肉 + 糖 |
| **神秘不明肉** | 50% 好吃了（生命恢复+饱和），50% 后悔一辈子（中毒+饥饿） | 腐肉 + 蜘蛛眼 + 糖 |

## 三、命令

命令不需要 OP 权限（快乐不应该被权限限制），单人游戏即使没开作弊也能用。

```
/mindbreak                      查看帮助
/mindbreak toggle               开启 / 关闭整活
/mindbreak intensity <1-3>      设置强度：1=温柔，2=正常，3=不做人
/mindbreak trigger <事件id>     立刻触发指定事件
/mindbreak list                 列出全部 43 个事件 id
/mindbreak gift                 领取五件神器
/mindbreak chaos                随机五连发（请站稳）
/mindbreak stats                查看当前强度、状态、累计整活次数
```

常用事件 id：

`chat_spam` `inventory_shuffle` `item_steal` `fake_diamond` `levitation`
`chicken_invasion` `mob_taunt` `tnt_stalker` `diamond_rain` `weather_chaos`
`time_chaos` `spooky_sound` `total_chaos` `fake_death` `chat_takeover`
`anvil_prank` `fake_ore` `fake_player_chat` `swap_players` `neck_crack` …（完整列表用 `/mindbreak list`）

## 四、安装

1. 安装 **Fabric Loader 0.16.x**（Minecraft **1.21.1**）
2. 安装 **Fabric API（0.116.x+1.21.1）**
3. 把 `mindbreak-1.0.0.jar` 扔进 `.minecraft/mods/`
4. 启动游戏。世界从此不再无聊。

> 客户端不需要安装任何额外内容；模组本身完全是服务端行为（单人游戏里由内置服务器执行）。
> 如果你开服务器，客户端和服务器都装同一个 jar 即可。

## 五、从源码构建

需要 **JDK 21**（1.21.1 强制要求 Java 21）。

```bash
# Windows
gradlew.bat build

# macOS / Linux
./gradlew build
```

产物：`build/libs/mindbreak-1.0.0.jar`（本仓库根目录也附带了一份已构建好的 `mindbreak-1.0.0.jar`，可直接使用）。

第一次构建会下载 Minecraft、Yarn mappings、Fabric API 等依赖，需要网络。
如果 `gradlew` 下载 Gradle 发行版很慢，可以把 `gradle/wrapper/gradle-wrapper.properties`
里的 `distributionUrl` 换成国内镜像（本项目默认已使用腾讯云镜像）。

---

## 六、配置说明

- 没有配置文件，所有开关都在 `/mindbreak` 命令里。
- 强度默认 2；嫌烦就用 `/mindbreak toggle` 关掉，重启游戏后会恢复默认（默认开、强度 2）。
- 模组没有 Mixin，全部基于 Fabric API 事件实现，兼容性相对友好。

## 八、项目结构

```

├── build.gradle                 # Fabric Loom 构建脚本
├── gradle.properties            # 版本号（MC 1.21.1 / Yarn / Fabric API）
├── settings.gradle
├── src/main/java/com/mindbreak/
│   ├── MindbreakMod.java        # 入口
│   ├── chaos/                   # 混沌引擎：事件注册表 / 调度器 / 文案 / 工具
│   ├── callback/                # 玩家行为回调（挖方块、右键、聊天、死亡……）
│   ├── command/                 # /mindbreak 命令
│   └── item/                    # 五件神器
├── src/main/resources/
│   ├── fabric.mod.json
│   ├── assets/mindbreak/        # 纹理、模型、语言文件、图标
│   └── data/mindbreak/recipe/   # 物品合成配方
└── assets-src/gen_assets.py     # 美术资源生成脚本（Pillow）
```
